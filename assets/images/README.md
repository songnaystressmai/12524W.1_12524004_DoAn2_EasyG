# Thư mục ảnh của EasyG

Đặt ảnh của bạn vào đúng thư mục con với đúng tên file bên dưới. Nếu chưa có ảnh, website tự hiển thị ô màu kèm chữ cái đầu tên, nên không bị lỗi giao diện.

## logo/
- `logo.png` – logo EasyG (khuyên dùng PNG nền trong suốt hoặc nền trắng, vuông ~256×256). Hiện ở header, tự thay cho chữ “E”.
